# 📚 Sistema de Biblioteca

Projeto desenvolvido em **ASP.NET Web Forms (.NET Framework)** para praticar desenvolvimento web com C#.

## 🚀 Objetivos do projeto

Este projeto foi criado para colocar em prática conceitos como:

- ASP.NET Web Forms
- C#
- Programação Orientada a Objetos (POO)
- Arquitetura em camadas
- GridView
- Services
- Git e GitHub

## 🚧 Status do projeto

O projeto está em desenvolvimento e será atualizado conforme novos conceitos e funcionalidades forem sendo implementados durante os estudos.

### Funcionalidades previstas:

- Cadastro de leitores
- Empréstimo de livros
- Devolução de livros
- Edição de registros
- Consumo de uma API para consulta e cadastro de livros
